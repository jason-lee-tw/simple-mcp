# Python naming convention

## Test file naming convention

- All the Python test file should named as `*_test.py` where the `*` is the target production code file.
  - For example: target `memory_service.py`, the test file should be named `memory_service_test.py`.
- Test file should be same folder with the target production code file.
  - For example: target `src/memory/memory_service.py`, the test file should be `src/memory/memory_service_test.py`
